This project demonstrates data analysis and visualization in Microsoft Excel using the Titanic dataset. 
It includes data cleaning, calculated columns, Pivot Tables, Pivot Charts, dashboards, slicers, and statistical analysis to explore passenger demographics, survival rates, age groups, fare distribution, and other key insights. 
The project showcases Excel's analytical capabilities for transforming raw data into interactive and meaningful business reports.

Skills Used:

Microsoft Excel
Pivot Tables & Pivot Charts
Dashboards
IF, COUNTIF, COUNTIFS, SUMIFS, AVERAGE
Conditional Formatting
Data Filtering & Sorting
Data Visualization
Statistical Analysis
